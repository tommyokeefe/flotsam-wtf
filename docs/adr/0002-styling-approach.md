# Astro scoped styles + Sakura, no utility framework

Sakura (sakura-vader theme) stays the base stylesheet. For styling beyond what Sakura's classless defaults cover (nav, tags, search UI, thumbnails), we use Astro's native per-component scoped `<style>` blocks rather than adopting a utility framework like Tailwind. `global.css` holds only a small set of shared CSS custom properties (colors/spacing pulled from sakura-vader's palette) as tokens; everything component-specific is colocated with that component. Chosen to avoid a new dependency and keep styling additions as low-friction and colocated as the per-post content structure (ADR 0001), at the cost of occasionally duplicating a small value across components — acceptable at this site's scale, promotable to a shared token later if a value actually recurs often.

**Amended by [ADR 0003](0003-one-h1-per-page.md):** `global.css` also holds a small set of genuinely global utility classes, currently `.portrait-right`/`.portrait-left` and `.visually-hidden`. The default is unchanged — colocate styling with its component, and duplicate a small value rather than share it prematurely — but a class that belongs to no single component and is easy to get subtly wrong (`.visually-hidden` is a fiddly clip-rect incantation) is better defined once than copy-pasted. Promote to `global.css` when a second consumer actually appears, not in anticipation of one.
